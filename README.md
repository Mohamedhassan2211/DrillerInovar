# Otago Property Explorer

خريطة لعرض العقارات وقطع الأراضي في منطقة Otago في نيوزيلندا. البيانات من خدمة ORC:

https://maps.orc.govt.nz/arcgis/rest/services/PropertyExternal/MapServer

تختار المنطقة ثم الطريق ثم الأرض، فيظهر popup فيه بيانات الأرض وطول كل ضلع والمساحة والمحيط، وتقدر تحفظ البيانات دي في ملف JSON على الباك اند، عن طريق API معمول بـ ASP.NET Core. وتقدر كمان ترسم على الخريطة وتشوف طول كل ضلع رسمته، وتحفظ الرسم في Shapefile وتحمّله تاني، وتحوّل الإحداثيات من جغرافي لمتري والعكس. وتقدر كمان تاخد صورة خريطة للأرض من الـ API، فبياناتها بتتسجل في ملف images.json وتفتحها في تبويب جديد.

الخريطة معمولة بـ ArcGIS Maps SDK for JavaScript (نسخة 5.1، الـ component `<arcgis-map>`) ومتحملة من الـ CDN. الخريطة الأساسية من OpenStreetMap، فمش محتاجة API key.

الكود بيستخدم اللي موجود جاهز في الـ SDK بدل ما يكتبه من الأول:

- الاستعلامات من الخدمة بـ `rest/query` (`executeForIds` و `executeQueryJSON`).
- المساحة والمحيط والمسافة بين الأرض والطريق بـ `areaOperator` و `lengthOperator` و `distanceOperator`.
- معرفة إذا كانت الأرض بتتقاطع مع الرسم بـ `intersectsOperator`.- التحويل لـ WGS84، وتحويل الرسم من Web Mercator لـ NZTM، بـ `projectOperator`، والخريطة بترسم بيانات NZTM مباشرة.
- الرسم على الخريطة بـ `Draw`.
- تحويل الإحداثيات بين WGS84 و NZTM بالمكوّن `<arcgis-coordinate-conversion>`.
- الطباعة بـ `takeScreenshot` بتاع `<arcgis-map>`: زرار الطباعة اللي على الخريطة تحت زراير الـ zoom بياخد صورة من الخريطة ويحطها في الصفحة، وبعدين `window.print()` بيفتح نافذة الطباعة، والـ `@media print` في style.css بيخفي كل حاجة غير الصورة وبيخلي الورقة بالعرض.
- الـ popup بـ `<arcgis-popup>` و `PopupTemplate`.
- القوائم والزراير والصفحات من Calcite (`calcite-combobox` و `calcite-button` و `calcite-list` و `calcite-tabs`)، وهي بتتحمل مع الـ SDK.

الشريط الجانبي فيه صفحتين بتتنقل بينهم من فوق: صفحة "الأراضي" فيها زرار التحديد من الخريطة وزرار تحويل الإحداثيات والقوائم وزرار الحفظ وزراير صورة الأرض، وصفحة "الرسم" فيها زرار الرسم وزراير حفظ الرسم وتحميله وقايمة أطوال الأضلاع. الرسايل تحت الصفحتين فبتظهر في الاتنين، وبتفضل باينة تحت حتى لو الشريط فيه scroll. الصفحات معمولة بـ `calcite-tabs` في index.html بس، والـ JS زي ما هو لأن الزراير والقوائم ليها نفس الـ `id`. والتنقل بين الصفحات مش بيوقف التحديد أو الرسم لو شغالين.

كل صفحة فيها زرار مسح: "مسح الاختيارات" بيفضّي القوائم والحاجات المرسومة للأرض والطريق ويقفل الـ popup ويخفي زرار "عرض الصورة"، ولو التحديد من الخريطة شغال بيوقفه (`resetLand` في js/main.js، وبتستخدم `resetFrom(1)` الموجودة). و "مسح الرسم" بيمسح الرسم وقايمة أطوال الأضلاع، ولو بترسم بيلغي الرسم من غير ما يكمّله، والضغط على الأراضي بيرجع مش بيفتح حاجة (`resetDrawing` في js/main.js و `clearDrawing` في js/mapView.js). كل زرار بيمسح صفحته بس، والخريطة مش بتتحرك.


## التشغيل

المشروع جزئين: الصفحة، والـ API اللي بيحفظ الأراضي في ملف JSON. الصفحة بتشتغل من غير الـ API، لكن زرار الحفظ محتاج الـ API يكون شغال.

### الـ API

مكتوب بـ ASP.NET Core على .NET 10، ومحتاج .NET 10 SDK (بيتسطب مع Visual Studio 2026).

افتح `backend/OtagoApi.slnx` في Visual Studio ودوس Run (أو F5). الـ API بيشتغل على `http://localhost:5000`، والمتصفح بيفتح على `http://localhost:5000/api/lands` وفيه الأراضي اللي اتحفظت. لما توقف الـ Run، الحفظ من الصفحة بيطلع رسالة خطأ.

أو من الترمنال:

```
cd backend
dotnet run
```

### الصفحة

الكود مكتوب كـ ES modules، فلازم يشتغل من local server. لو فتحت index.html مباشرة من المتصفح مش هيشتغل.

من VS Code استخدم Live Server (كليك يمين على index.html ثم Open with Live Server)، أو من الترمنال:

```
npx serve .
```

أو

```
python -m http.server 8080
```

ولو الصفحة على IIS، الـ `web.config` اللي في فولدر المشروع بيخلي IIS يبعت `Cache-Control: no-cache` مع كل ملف، فالمتصفح بيسأل كل مرة هل الملف اتغير. لو ما اتغيرش بيرجع 304 من غير تحميل، ولو اتغير بيجيب الجديد. من غيره المتصفح كان ممكن يستخدم نسخة قديمة من ملف JS مع نسخة جديدة من ملف تاني، فيطلع error زي `does not provide an export named`.

Live Server بيعمل reload للصفحة لما أي ملف في المشروع يتغير، فـ `.vscode/settings.json` بيخليه يتجاهل فولدر `backend` وفولدر `Api` (الـ API اللي اتعمله Publish على IIS). من غيره الصفحة كانت هتعمل reload مع كل حفظ أو صورة أرض (لأن `lands.json` أو `images.json` بيتغير) ومع كل build أو Publish، فزرار "عرض الصورة" كان بيختفي بعد ما يظهر على طول.


## خطوات الاختيار

1. المنطقة: من طبقة Street Address (رقم 2)، وهي القيم المختلفة لحقل `suburb_locality`.

2. الطريق: من طبقة Roads (رقم 3) عن طريق حقل `locality`. الطريق اللي على حدود منطقتين اسم المنطقة فيه بيكون بالشكل `Maryhill-Mornington`، فالبحث بياخد الحالة دي في الاعتبار.

3. الأرض: من طبقتي ORC Properties (رقم 0) و LINZ Parcels (رقم 1). بيتم جلب الأراضي اللي بتلمس خط الطريق في حدود 15 متر (`ROAD_BUFFER_M` في config.js)، مع استبعاد قطع الطرق نفسها.

4. العنوان: العناوين اللي جوه الأرض المختارة.

كل خانة فيها بحث، تكتب جزء من الاسم وتختار بالماوس، أو بالأسهم وبعدين Enter.

الخدمة بترجع 1000 نتيجة بس في الطلب الواحد، والـ paging بتاعها (`start` و `num`) مش شغال صح مع البحث بالمكان زي البحث بالمسافة: بيقسّم كل اللي جوه المستطيل اللي حوالين الطريق على صفحات الأول، وبعدين يفلتر بالـ 15 متر، فكل صفحة بترجع شوية نتايج وبتقول إن لسه فيه. فلو استخدمناه، الطريق الطويل زي `Cumberland Street` بيحتاج 5 طلبات ورا بعض، و `State Highway 6A` في Queenstown بيحتاج 7، وبعض الأراضي بتتكرر. وفيه طرق عليها أكتر من 1000 أرض، زي `Frankton Road` (1305). علشان كده الدالة `query` في js/api.js بتبعت طلبين مع بعض: أول 1000 نتيجة، وأرقام النتايج كلها (`executeForIds`، ومالهاش حد). لو الطلب الأول جاب كل النتايج، وده اللي بيحصل مع أغلب الطرق، بتستخدمه على طول. ولو لأ، بتجيب البيانات بالأرقام 1000 ورا 1000 (`PAGE_SIZE` في config.js)، والطلبات دي كلها بتتبعت مع بعض مش ورا بعض.

الخريطة بترسم بس اللي بتختاره من القوائم: الطريق، وحدود الأرض مع طول كل ضلع، والعنوان. الخدمة مفيهاش حدود للمناطق، فلما تختار منطقة الخريطة بتروح لمكان طرقها من غير ما ترسم حاجة.


## التحديد من الخريطة

بدل القوائم تقدر تضغط زرار "تحديد الأرض من الخريطة"، وتقرّب الخريطة لحد ما حدود العقارات تظهر (من مقياس 1:10,000 تقريباً)، وتضغط على الأرض. الحدود دي بتظهر وقت التحديد بس، والضغط على الزرار تاني بيلغي التحديد.

لو المكان فيه عقار بيتختار، ولو مفيش بتتختار القطعة. طبقة ORC Properties فيها الطرق كمان كعقارات باسم `Road`، فالضغط على الشارع بيختار الطريق كعقار.

بعدها القوائم بتتملي لوحدها كأنك اخترت منها بالترتيب: المنطقة، وبعدين الطريق، وبعدين الأرض نفسها. المنطقة والطريق بيتحددوا من مكان الأرض على طبقة Roads (رقم 3) مش من العناوين اللي جواها، فبيتملوا حتى لو الأرض مفيهاش عنوان (الكود في js/locate.js):

- البحث عن الطرق بيكون في حدود 250 متر حوالين الأرض، ولو مفيش ولا طريق (أرض ريفية بعيدة) بيوسع لحد 5 كيلو (`ROAD_SEARCH_M` في config.js).
- الطريق: أقرب طريق للأرض، إلا لو الأرض عقار وحقل `StreetName` بتاعه بيسمي طريق تاني من دول (مثلاً `Argyle St` يعني Argyle Street)، فبيتختار ده. ده بيفرق في الأرض اللي على ناصية، واللي ورا أراضي تانية. ولو فيه طرق في حدود 15 متر من الأرض (`ROAD_BUFFER_M`)، الاختيار بيكون منها بس.
- المنطقة: من حقل `locality` بتاع الطريق، يعني المنطقة اللي الطريق بيظهر تحتها في قائمة الطرق. لو الطريق على حدود منطقتين (زي `Musselburgh-Saint Clair`) بتتاخد منطقة أقرب طريق حوالين الأرض تابع لواحدة بس منهم.

الأرض اللي بعيدة عن طريقها أكتر من 15 متر مش بتكون في قائمة أراضي الطريق، فبتتضاف لها. لو منطقة الطريق مش في قائمة المناطق (أماكن برا Otago زي Omarama) بيتملى الطريق بس، ولو مفيش أي طريق في حدود 5 كيلو المنطقة والطريق بيفضلوا فاضيين، واللي فاضي بيتكتب `null` في ملف JSON.

المنطقة ممكن تختلف عن الحي المكتوب في عنوان الأرض لما طبقة الطرق تكون مسجلة الطريق كله تحت منطقة واحدة، زي `Frankton Road` المسجل تحت Frankton حتى الجزء اللي جوه Queenstown.

وبعد ما الأرض تتحدد، أقرب طريق ليها بيتلوّن بالأصفر، وفي نص الأرض بيظهر اسمه والمسافة بالمتر. دي نفس المسافة اللي `locateLand` بتحسبها بـ `distanceOperator` علشان تختار الطريق، فمفيش حساب زيادة (`nearest` في js/locate.js و `showNearestRoad` في js/mapView.js). أقرب طريق ممكن يكون غير الطريق اللي اتختار في القائمة (زي الأرض اللي على ناصية)، والمسافة لحد خط نص الطريق مش لحد الرصيف، لأن طبقة Roads خطوط. التظليل بيتمسح لما تختار أرض تانية، وبيظهر في التحديد من الخريطة بس.


## الرسم على الخريطة

زرار "الرسم على الخريطة" في صفحة "الرسم" بيخليك ترسم بالضغط على الخريطة. كل ضغطة بتحط نقطة، ونوع الرسمة بيتحدد من عدد النقط:

- نقطة واحدة: نقطة.
- نقطتين: خط.
- 3 نقط أو أكتر: مضلع (polygon)، بيتقفل لوحده من آخر نقطة لأول نقطة.

وانت بترسم، آخر نقطة في الشكل بتمشي مع الماوس علشان تشوف الضغطة الجاية هتعمل إيه. علشان تخلّص اضغط دبل كليك (أو Enter)، أو دوس على الزرار تاني (كلامه بيبقى "إنهاء الرسم"). حرف Z بيشيل آخر نقطة و R بيرجّعها، ولو خلّصت من غير ولا نقطة الرسم بيتلغي. ووقت الرسم زرار التحديد بيبقى مقفول، ووقت التحديد زرار الرسم بيبقى مقفول، علشان الضغطة على الخريطة ما تتحسبش للاتنين.

بعد الرسم بتظهر قايمة "أطوال أضلاع الرسم" تحت زرار الرسم، فيها طول كل ضلع بالمتر، ورقم كل ضلع وطوله بيظهر في نصه على الخريطة بنفس شكل أضلاع الأرض. الخط ليه ضلع واحد، والمضلع اللي فيه N نقطة ليه N ضلع، والنقطة مالهاش أضلاع. كل خط بين نقطتين ضغطت عليهم بيتحسب ضلع، من غير دمج النقط اللي على خط واحد زي أضلاع الأرض، لأن كل نقطة انت اللي حاططها. وكل رسمة جديدة بتمسح اللي قبلها، والرسم مش بيتحفظ في ملف JSON بتاع الأراضي، بيتحفظ لوحده في Shapefile (شوف "حفظ الرسم وتحميله" تحت).

لما تضغط على ضلع في القايمة، الخريطة بتقرّب عليه والضلع بيتلوّن بالبرتقالي علشان يبان، والضلع ده بيفضل متعلّم في القايمة (`showSide` في js/mapView.js).

بعد ما تخلّص الرسم، تقدر تضغط على أي أرض جوه الرسم أو بتتقاطع معاه فيفتح الـ popup بتاعها بس، من غير ما القوائم تتملي ومن غير ما الخريطة تتحرك. لو جزء من الأرض جوه الرسم تقدر تضغط على أي حتة فيها، حتى الجزء اللي برا الرسم. ولو ضغطت على أرض تانية الـ popup القديم بيتقفل ويفتح بتاع الأرض الجديدة. والأرض اللي مش بتلمس الرسم خالص مش بتفتح حاجة وبتظهر رسالة. لو الرسم نقطة بتفتح الأرض اللي فيها النقطة، ولو خط بتفتح الأراضي اللي الخط معدّي عليها.

ده بيفضل شغال طول ما الرسم موجود. زرار "تحديد الأرض من الخريطة" بيفضل زي ما هو (بيحدد من أي مكان وبيملى القوائم)، ولما التحديد يخلص الضغط بيرجع للرسم تاني. ولو عايز توقفه ارسم من جديد وخلّص من غير ولا نقطة.

الأرض بتيجي من الخدمة بمكان الضغطة (`getLandsAt`)، وبعدين `intersectsOperator` بيشوف هل هي بتتقاطع مع الرسم ولا لأ، بعد ما الرسم يتحوّل لـ NZTM بـ `projectOperator` (الدالة `intersects` في js/geometry.js). والـ popup فيه نفس بيانات popup الأرض العادي، وبيفتح بـ `openPopup` اللي بيقفل القديم لوحده (`openDrawnLand` في js/main.js و `showLandPopup` في js/mapView.js).

الرسم معمول بـ `Draw` من الـ SDK بنوع `multipoint`: الـ `Draw` بيستقبل الضغطات ويدّي النقط، والكود بيرسم الشكل المناسب لعددها (`startDrawing` في js/mapView.js). مش `polyline` لأنه مش بيقبل يخلّص بأقل من نقطتين. والـ `Draw` هو كمان اللي بيمنع الـ popup وقت الرسم، وبيمنع الدبل كليك إنه يعمل zoom.

النقط بتيجي من الخريطة بـ Web Mercator، فالأطوال بتتحسب بعد ما الشكل يتحوّل لـ NZTM بـ `projectOperator`، وكل ضلع بفيثاغورس زي أضلاع الأرض (`measureSides` في js/geometry.js). من غير التحويل الأطوال كانت هتطلع أكبر حوالي 1.44 مرة (شوف نظام الإحداثيات تحت). مثلاً الرسم على أركان 43 Argyle St بيدّي نفس أطوال أضلاعها من الخدمة: الضلع اللي طوله 18.91 متر بيطلع 18.91، ولو اتحسب بـ Web Mercator كان هيطلع 27.20.

### حفظ الرسم وتحميله

زرار "حفظ الرسم (Shapefile)" بينزّل الرسم في ملف `drawing.zip` على الجهاز، من غير باك اند ولا داتا بيز. جوه الـ zip ملفات الـ Shapefile الأربعة: `drawing.shp` (الشكل) و `drawing.shx` و `drawing.dbf` و `drawing.prj` (نظام الإحداثيات). الزرار بيبقى مقفول لحد ما يبقى فيه رسم.

زرار "تحميل رسم محفوظ" بيفتح اختيار ملف، تختار الـ zip اللي اتحفظ، فالرسم بيترسم تاني مكانه والخريطة بتروح له، وبتظهر نفس أطوال الأضلاع، والضغط على الأراضي جوه الرسم بيشتغل زي الرسم العادي، لأن الرسم اللي اتحمّل بيعدّي على نفس `drawingDone`. التحميل بيمسح الرسم اللي قبله، وتقدر تحفظه تاني. ولو الملف مش zip فيه رسم محفوظ بتظهر رسالة خطأ. ووقت التحديد من الخريطة زرار التحميل بيبقى مقفول زي زرار الرسم.

الـ SDK مفيهوش كتابة Shapefile، فالكتابة بمكتبة `@mapbox/shp-write` والقراية بمكتبة `shpjs`، والاتنين متحملين من unpkg في index.html. `shp-write` بيكتب الـ `.prj` بتاع WGS84، فالرسم بيتحوّل للدرجات قبل الحفظ بـ `toWgs84`. و `shpjs` بيرجّع الرسم بالدرجات، والخريطة بتعرضه كده على طول، والأطوال بتتحسب بعد التحويل لـ NZTM زي أي رسم. و `shpjs` في المتصفح بيرجّع الخط كـ `MultiLineString`، فالكود بيقبل `LineString` و `MultiLineString`. الكود في js/shapefile.js (`saveShapefile` و `loadShapefile`) و `showSavedDrawing` في js/mapView.js.


## تحويل الإحداثيات

زرار "تحويل الإحداثيات" في صفحة "الأراضي" بيظهر المكوّن الجاهز `<arcgis-coordinate-conversion>` من الـ SDK تحت يمين الخريطة، والضغط عليه تاني بيخفيه. فيه سطرين:

- XY: خط الطول ثم خط العرض بالدرجات (WGS84).
- NZTM: الـ E ثم الـ N بالمتر (NZTM2000).

وانت بتحرّك الماوس على الخريطة السطرين بيتغيروا مع مكانه. ولو عايز تحوّل إحداثيات معينة: دوس القلم، واختار النظام اللي هتكتب بيه، واكتب الرقمين وبينهم فاصلة، ودوس "تحويل". السطرين بيتملوا بالنظامين، وبتظهر علامة على الخريطة مكان النقطة، ولو علّمت "انتقال إلى الموقع" الخريطة بتروح لها. وزرار الدبوس بيخليك تختار نقطة بالضغط عليها.

مثلاً 43 Argyle St: `170.479037, -45.884324` بالـ XY هي `1404391.48, 4915714.27` بالـ NZTM، والعكس.

الـ NZTM مش من الأنظمة اللي جاية مع المكوّن، فبيتضاف له كـ `Format` في js/mapView.js، بنفس طريقة مثال Esri للأنظمة الإضافية. الـ `spatialReference` بتاعه 2193، فالمكوّن هو اللي بيحوّل له من نظام الخريطة، و `reverseConvert` بتحوّل النص اللي بيتكتب لنقطة NZTM. يعني التحويل في الاتجاهين بيتم بالـ SDK، زي `toWgs84` في js/geometry.js.

خلي بالك: في XY خط الطول الأول (`170.47, -45.88`)، ولو اتكتب بالعكس المكوّن بيقول إن الإحداثيات غلط. والمكوّن معروض من الشمال لليمين (`direction: ltr` في css/style.css)، لأن في الصفحة العربية علامة السالب بتاعة خط العرض كانت بتتنقل من مكانها.

## نظام الإحداثيات

البيانات في الخدمة بنظام EPSG:2193 (NZGD2000 / NZTM2000). ده نظام projected والوحدة فيه المتر، وهو إسقاط Transverse Mercator واحد لكل نيوزيلندا (مش UTM zones).

الخريطة بتعرض بـ Web Mercator (EPSG:3857). الـ SDK بيحوّل اللي بنرسمه من NZTM لوحده، فالكود بيدي الخريطة بيانات الخدمة زي ما هي.

كل الاستعلامات بتطلب البيانات بـ NZTM (`outSpatialReference` في js/api.js)، والحسابات كلها بتتم بالمتر مباشرة: المساحة والمحيط بـ `areaOperator` و `lengthOperator`، وطول الضلع بفيثاغورس. النتايج بتطابق `SHAPE.STArea()` و `SHAPE.STLength()` اللي راجعين من الخدمة.

ليه مش بنحسب بالدرجات؟ لأن الدرجة مالهاش طول ثابت. عند Dunedin درجة العرض حوالي 111.1 كم لكن درجة الطول حوالي 77.6 كم بس. و Web Mercator كمان مش مناسب للقياس، لأنه عند خط عرض Dunedin (حوالي 45.9 جنوب) بيكبّر المسافات حوالي 1.44 مرة.

الإحداثيات بالدرجات (WGS84 / EPSG:4326) اللي في الـ popup وملف JSON بتتحسب في js/geometry.js: الدالة `toWgs84(point)` بتحول من متر إلى lat/lng بـ `projectOperator`.

مثال لركن من أرض 43 Argyle St, Dunedin:

```
NZTM2000 : E 1404394.273   N 4915737.490
WGS84    : -45.8841162, 170.4790823
```

ملحوظة: التحويل بيعتبر NZGD2000 هو نفسه WGS84 تقريباً. الفرق بينهم في حدود متر بسبب حركة الصفائح، وده مقبول في خريطة ويب. وكمان الطول المحسوب على NZTM هو طول على مستوى الإسقاط، والفرق بينه وبين الطول الحقيقي صغير جداً في Otago (حوالي 7 سم لكل كيلو في Dunedin، وحوالي متر لكل كيلو في Queenstown).


## حساب الأضلاع

الضلع هو المسافة بين ركنين. حدود LINZ أحياناً فيها نقط زيادة على نفس الخط المستقيم (عند أركان الأراضي اللي جنبها)، والنقط دي مش بتتحسب أركان. أي نقطة الاتجاه بيتغير عندها بأقل من درجة واحدة بتتدمج في نفس الضلع (`CORNER_MIN_ANGLE` في geometry.js).

لو الضلع منحني (قوس) فطوله هو مجموع أطوال الأجزاء الصغيرة اللي مكوناه.

## صورة الخريطة عند نقطة

`GET /api/map-image?x=...&y=...` بياخد نقطة بالدرجات (WGS84)، `x` خط الطول و `y` خط العرض، ويرجّع صورة PNG مقاسها 1000×700 من خريطة Esri `World_Basemap_GCS_v2`، والنقطة في نصها بعلامة حمرا. مثلاً 43 Argyle St:

```
http://localhost:5000/api/map-image?x=170.4790369&y=-45.8843242
```

الرابط بيفتح الصورة في المتصفح على طول، وينفع يتحط في `<img src>`. والخريطة دي للعالم كله، فالـ API شغال لأي مكان مش Otago بس.

الخريطة دي Vector Tiles، يعني بيانات مش صور، ومفيهاش `export` زي الـ MapServer اللي يرجّع صورة. فالـ API بيبعت الخريطة والنقطة بـ `HttpClient` لخدمة الطباعة الجاهزة من Esri (Export Web Map Task)، والخدمة بترسمهم وترجّع رابط للصورة، والـ API بينزّلها ويرجّعها هي. مش بيرجّع الرابط نفسه لأنه مؤقت، وبيتمسح من سيرفر Esri بعد شوية.

الصورة بمقياس 1:2000 (`scale`)، والخدمة بتحط النقطة في نص الصورة. ولو `x` أو `y` ناقصين أو مش أرقام أو برا الحدود (`x` من -180 لـ 180، و `y` من -90 لـ 90) بيرجع 400 من غير ما يبعت حاجة لـ Esri. ولو خدمة الطباعة رجّعت خطأ بيرجع 502 ومعاه رسالة الخطأ بتاعتها. الكود في `backend/Controllers/MapImageController.cs`.

### بيانات الصورة (JSON) وملف images.json

`GET /api/map-image/info?x=...&y=...` بياخد نفس النقطة، ويرجّع JSON بنفس شكل API الشركة اللي بيجيب صورة النقطة من 2GIS:

```json
{
  "status": true,
  "errorCode": 0,
  "error_Code": null,
  "gis_code": "تم اخذ صوره",
  "imageUrl": "http://localhost:5000/api/map-image?x=170.4790369&y=-45.8843242",
  "urlEsri": "https://basemaps.arcgis.com/arcgis/rest/services/World_Basemap_GCS_v2/VectorTileServer"
}
```

`imageUrl` هو رابط الصورة اللي فوق بنفس النقطة، مش رابط خدمة الطباعة المؤقت، فبيفضل شغال على طول زي رابط 2GIS اللي فيه الإحداثيات. الرابط بيتعمل من الطلب نفسه بـ `Url.ActionLink`، فعلى IIS بيطلع `http://localhost/Api/api/map-image?...`. والرد بيتكتب بنفس إعدادات ملف images.json (`JsonOptions`)، علشان العربي يظهر مقروء في المتصفح.

وكل طلب صحيح بيضيف record في آخر `backend/Data/images.json` (وعلى IIS في `Api/Data/images.json`)، زي `lands.json`، حتى لو النقطة اتطلبت قبل كده. والطلب الغلط (400) مش بيضيف حاجة:

```json
{
  "savedAt": "2026-10-25T09:32:45.5436117Z",
  "x": 170.4790369,
  "y": -45.8843242,
  "imageUrl": "http://localhost:5000/api/map-image?x=170.4790369&y=-45.8843242",
  "urlEsri": "https://basemaps.arcgis.com/arcgis/rest/services/World_Basemap_GCS_v2/VectorTileServer"
}
```

### زرار صورة الأرض

في صفحة "الأراضي"، بعد ما تختار أرض، زرار "صورة الأرض" بيبعت نص الأرض (نفس `center` اللي بيتحفظ في lands.json) بالدرجات لـ `info`، فبيتسجل record في images.json ويظهر تحته زرار "عرض الصورة". الزرار ده `calcite-button` ليه `href` هو `imageUrl` و `target="_blank"`، فبيفتح الصورة بمقاسها الكامل في تبويب جديد من غير كود للضغطة. والتبويب بياخد 2 لـ 3 ثواني، لأن خدمة الطباعة بترسم الصورة ساعتها.

لما تختار أرض تانية أو تمسح الاختيارات، "عرض الصورة" بيختفي و "صورة الأرض" بيتقفل لحد ما الأرض الجديدة تتحدد، زي زرار الحفظ (`saveImage` و `resetFrom` في js/main.js). والطلب نفسه في `saveMapImage` في js/exporter.js، وبيستخدم هو و `saveLandRecord` نفس الدالة `callApi`، اللي بتبعت للـ API وبتطلع رسالة لو مش شغال.
